# Операция «ZIVALOB» — протокол перерегистрации v3

Дата фиксации: по факту уточнения «мыло подтверждено ДО форума; отдельного форумного подтверждения не существует; EXBO-ID-связанные аккаунты проходят спокойно».

---

## 1. Итоговый диагноз (v3, все альтернативы сняты)

| Гипотеза | Статус | Основание |
|---|---|---|
| А. Ранговый гейт (новичкам нельзя вне «Болот») | ❌ снята | Тест «Болот» провален — canReply=false даже там |
| Б. Неподтверждённая почта / SSO-код ≠ верификация | ❌ снята | Мыло подтверждено на EXBO ID **до** попыток постинга; отдельного форумного подтверждения не существует |
| В. Карантин по IP рождения (Tor-exit → fof-geoip/fof-spamblock/stopforumspam) | ✅ **единственная живая** | Аккаунт-специфичный глобальный canReply=false при том, что обычные EXBO-ID-аккаунты проходят свободно |
| Г. Фильтр нецензурного ника (вторичная, маловероятная) | ⚠️ дикая карта | Регистрацию не заблокировал, но мог добавить флаг |

**Следствие:** флаг выставлен в момент рождения аккаунта. Подтверждениями, ожиданием и повторными логинами это не лечится. Лечится только модератором (= деанон) или чистой перерегистрацией.

---

## 2. Старый аккаунт: вердикт

- **Заморозить.** Не удалять, не писать в саппорт/тикет (любой контакт = частичный деанон).
- **Никогда больше не логиниться через Tor** — каждый логин это новая проверка IP-репутации и обновление флага.
- Потеря некритична: 0 постов, 0 репутации, публичного следа у ника нет.

---

## 3. Новый аккаунт: чеклист рождения

1. **Сеть:** WARP полный туннель, Tor выключен полностью. Перед регистрацией посмотреть страну выхода WARP и **не менять её** между регистрацией / прогревом / публикацией.
2. **Почта:** Proton (или Tuta). Запрещено: семейство cock.li (один оператор, одна репутация), алиасы из блэклистов (SimpleLogin / addy.io / duck.com).
3. **Браузер — ВЫПОЛНЕНО: выделенная Опера.** Отдельная установка = отдельные куки/хранилище/сессии; изоляция решена на уровне браузера, а не профиля. Правила эксплуатации:
   - вся операция живёт только в Опере: Proton, регистрация EXBO ID, форум, переходы по ссылкам из писем;
   - в основной браузер, где живёт игровой EXBO ID, forum/passport не заносить — сессии паспорта не должны пересекаться;
   - в Опере НЕ логинить Opera Account (синхронизация = лишний якорь) и НЕ включать встроенный «VPN» (это прокси; поверх системного WARP даст задвоенный выход);
   - старый карантинный аккаунт и cock.li-почту в Оперу не открывать вообще;
   - WARP системный — трафик Оперы покрыт по умолчанию.
4. **Ник ≤ 16 символов — ограничение действует только на стороне Эксбо-ИД/Форума. ВЫБРАН: `PatronOfSanity` (14).** Финальное решение по почте и бренду:
   - публичная почта в посте: `ProtonMailAccNum1@proton.me` — существующий Proton, сознательно списывается на операцию; в disposable-блэклистах Proton чист (проверено ранее); история SimpleLogin-алиасов форуму не видна — форум видит только сам адрес Proton, а SL-адреса публично с ним не связаны;
   - полный бренд живёт ПОДПИСЬЮ в тексте телеги: `— PatronSaintOfFuckYourSanity`; ник карантинного акка (PatronSaintSani) публично не светился (0 постов), значит связку видит только автор;
   - в нике и в почте корреляций с брендом нет — ни автоматика, ни ручной взгляд модерации ничего не свяжут;
   - радиус «сожжения» почты принят: прочие дела, когда-либо связанные с этим Proton, попадают в периметр при компрометации — осознанное решение автора.
5. **Новый EXBO ID** не логинить в лаунчер игры и ни с чем больше не связывать.
6. **Подтвердить форумную почту сразу** после регистрации: код/ссылка из Proton открывается в той же Опере — переход по ссылке из письма. Отдельного «изголья» не требуется: изоляция уже выполнена самим фактом выделенного браузера (см. п. 3).
7. Пароль/отпечаток/всё прочее — **ноль** пересечений со старым аккаунтом.

## 4. Прогрев (2–3 дня)

- **День 0:** регистрация + подтверждение почты + чтение правил «Болот» (проверить, нет ли пункта «N дней/сообщений до публикации»).
- **День 1:** 1–2 безобидных поста: без ссылок, без картинок, обычная речь.
- **День 2:** 2–3 ответа в живых тредах; убедиться, что canReply=true везде и ни один пост не ушёл в предмодерацию.
- Публикация — только после двух «зелёных» дней.

## 5. Публикация телеги

- **Первый пост:** полный текст `TELEGA_STALZONE_COMBI_v3.txt` — БЕЗ ссылок на файлообменники; вместо них блок «📦 Полный архив. Вопрос доставки» с почтой ProtonMailAccNum1@proton.me (плейсхолдер заменён — правок в тексте не осталось).
- **Второй пост** (свой ответ через 1–2 часа): прямые ссылки gofile/mega из заготовки `REPLY2_LINKS_SNIPPET.txt` (верхняя часть файла с чеклистом не публикуется). Снесут ссылки — почта из первого поста продолжает работать.
- Все действия в Опере; WARP полный туннель.
- Старый аккаунт в день публикации не трогать вообще.
- Гео выхода WARP в день публикации = гео регистрации.

---

## 6. Контингенция (если чистый акк тоже canReply=false)

1. Перерегистрация с полностью чистым ником (проверка гипотезы Г).
2. Выдержка 72 ч без действий — возможно, все новые EXBO ID проходят невидимый карантин.
3. Перечитать закрепы/правила «Болот» на предмет скрытых гейтов для новичков.
4. Только после этого пересматривать модель (например, флаг вешается на сам EXBO Passport при рождении через VPN-класс IP, тогда — голый провайдерский IP без WARP).
