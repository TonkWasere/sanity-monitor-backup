## 2. Причина ложных «волн»: квота near-окна ~20–23 поста

Near-окно возвращает НЕ «блок номеров вокруг анкера», а ~20–23 БЛИЖАЙШИХ ВИДИМЫХ постов (с хаотичными дальними вбросами — см. 15-b §2). При анкорах через 50 номеров между окнами остаются дыры в десятки номеров. Объединение редких окон систематически выглядело как «полосы скрытых постов» — «полосы» повторяли промежутки между анкорами сетки. Все процентные оценки волн (45%, 46%, 33%, полосы #21–39/#112–139/#161–183 и т.п.) — **артефакт измерения, не свойство форума**.

Правило №1 протокола (обновлено): **объединение near-окон запрещено использовать для выводов о скрытиях.** Только: (а) полный индексный перебор + цикл анкеров, или (б) целевой анкер near=N для конкретного номера.

## 4. hide vs purge — статус вопроса

> **РЕШЕНО 03.10 (16-a):** автор из-под акка проверил профиль — Flarum-профиль показывает собственные скрытые посты серыми/свёрнутыми. ОБА пропавших поста Санити (#389 в d/195192 и #415 в d/195660) там — **HIDE, не purge**. Контент в БД сохранён, доступ автора сохранён. Ни одного purge за всю кампанию. Детали и протокол профильного канала — `16a_full_collection_three_threads.md` §1–2.

Индексный перебор не содержит скрытых постов: недостижимые номером отсутствуют и в нём. Значит гостевая поверхность едина: «номера нет» и в обсуждении, и в индексе. Различить hide (в БД, автор видит серым) и purge (вычищено из БД) изнутри гостя НЕВОЗМОЖНО. Разрешение — только авторская проверка: **если Санити сейчас видит #415 серым/свёрнутым → hide; если поста нет даже для автора → purge.** (На 02.10 вечером автор видел #415 серым — на тот момент точно hide; дальнейшая судьба неизвестна.)

## 5. Новая стандартная процедура съёмки треда (протокол)

```bash
# 1) полный индекс видимых постов (без артефактов), до пустой страницы:
curl -s 'https://forum.exbo.net/api/posts?filter%5Bdiscussion%5D=ID&page%5Bsize%5D=50&page%5Boffset%5D=0' \
  -H 'User-Agent: Mozilla/5.0' -H 'Accept: application/json'
# 2) lastPostNumber/commentCount/isSticky/isLocked:
curl -s 'https://forum.exbo.net/api/discussions/ID?page%5Bnear%5D=1' -H 'User-Agent: Mozilla/5.0' -H 'Accept: application/json'
# 3) недостижимые = 1..lastPostNumber минус номера из индекса
# 4) спорный конкретный номер N — целевое окно near=N (триангуляция)
```

Скорость: полный тред = ~8–13 запросов вместо ~60 анкеров; карта точная по построению.
