## 2. Откуда взялся ложный вывод 15-a «#69 скрыт»: хаотичное заполнение near-окон

Карта окна near=50 из среза 21:02 (23 поста):


Окно взяло сплошной ближний блок 40–61 и затем **вбросило два ДАЛЬНИХ поста (#133 и #144), пропустив ближние 60–89**. То есть заполнение квоты near-окна на exbo не является честным «ближайшим N видимым» — оно хаотично. Окно near=100 (21:02) при этом покрыло ровно 90–111.

Gap объединения окон — лишь **верхняя граница** скрытности, не доказательство. Доказательство скрытия — только целевое окно near=N с отсутствием поста N (как для #415 в 14-f) **плюс** отсутствие поста во всех окнах, чьи диапазоны его накрывают.

**Правило метода (в протокол):**
1. Каждый gap → целевой `page[near]=<номер пропуска>` (и соседний) до вывода о скрытии.
2. near-сетка обязана покрывать 1..lastPostNumber без дыр; контролировать перекрытие диапазонов окон, а не количество окон.
3. При любом спорном gap — контроль независимым источником (вид автора / другой сессии), как здесь.
