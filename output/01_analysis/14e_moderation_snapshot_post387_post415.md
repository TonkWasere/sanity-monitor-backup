## 2. Как найден номер #415 (gap-анализ)

Гость не получает скрытые посты из API вообще — ни атрибутов, ни номера. Номер снятого поста вычисляется по разрыву нумерации:

- Объединённая карта видимых номеров постов по трём окнам (near=387/400/412): **39 видимых постов подряд, #377 → #416**
- Единственный пропуск во всём диапазоне: **#415**
- Временные рамки: #414 создан 02.10 09:16:49 UTC, #416 — 02.10 17:44:47 UTC
- Пользователь: пост B запощен после #414 02.10, «провисел в общем обозрении пару часов точно», затем снят
- Вывод: **#415 — это снятый пост B**. Альтернативных разрывов в диапазоне нет.
