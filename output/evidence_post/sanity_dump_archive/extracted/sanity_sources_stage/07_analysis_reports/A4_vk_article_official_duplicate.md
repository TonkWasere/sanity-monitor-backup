## 7. Следствия для кампании

1. **Аргумент «технической невозможности» умер**: готовый текстовый слепок каждого патчноута существует и публикуется EXBO в собственном ВК-паблике в момент релиза. Flarum поддерживает таблицы — на форуме текста нет по выбору, не по ограничению.
2. **Инверсия доступности**: в каналах БЕЗ обсуждения (ВК-статьи, Steam) — полный текст с Ctrl+F; в канале ДЛЯ обсуждения (форум) — пиксели, которые нельзя процитировать, перечитать или погуглить. Там, где дискуссия — нет инструментария для неё.
3. **Near-miss 13-g становится кейсом-доказательством**: текстовая ВК-версия позволяет проверить цифру за 3 секунды Ctrl+F'ом; пиксельная форумная — потребовала OCR-бригады, и OCR один раз ошибся (43→45). Пиксели не просто неудобны — они ошибкоопасны для тех, кто цитирует.
4. **Задание PR-отделу (обновление)**: дублировать текстовую версию (уже существующую в ВК) в OP форумного патчноута. Себестоимость ~0: текст уже написан.
5. Возможный контр-аргумент «ВК-статья — это комьюнити-хаб, а не официальная документация» заранее опровергнут: ссылка на ВК-статью идёт из официального TG-канала в том же посте, что и форумная, без пометки «неофициально».
