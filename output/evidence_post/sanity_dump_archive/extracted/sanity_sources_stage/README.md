## 4. Кейс задокументированной ошибки (why it matters)

При разборе пикселей IMG 19–21 машинное распознавание (VLM×3 + Tesseract) уверенно прочитало «ЭМЧес» быстрый 45 / «Классический М9» обычный 45 / Zeus-77 сильный 145 — против Steam 43 / 43 / 143. Поверочная сверка с игрой и кропы строк (`verify_crops_near_miss/`) показали: **на пикселях 43 / 43 / 143**. Ошибка распознавания (глиф 3↔5 при мелком рендере) была бы опубликована как «расхождение», если бы не существовало текстовой версии для сверки.

Именно поэтому формат «только пиксели» опасен: цифру нельзя перечитать, процитировать или найти — только угадать. Текст в ВК-статье решает это за 3 секунды Ctrl+F; его просто нет на форуме.
